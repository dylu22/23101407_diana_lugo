## Actividad 14 — Privacidad por diseño

##Matriz de evaluación

| Problema | Principio afectado | Riesgo | Control propuesto |
|---|---|---|---|
| 1. Analítica tiene acceso directo a la tabla completa. | Mínimo privilegio. | Exposición de datos personales. | Crear vistas con los datos necesarios para las estadísticas. |
| 2. Se utilizan datos identificables para generar estadísticas. | Minimización de datos. | Exposición innecesaria de información. | Utilizar datos agregados o anonimizados. |
| 3. Los datos se conservan durante 12 años. | Limitación de la conservación. | Acumulación de información innecesaria. | Establecer plazos de conservación. |
| 4. No existe una política de retención. | Responsabilidad. | Conservación indefinida de datos. | Documentar una política de retención y eliminación. |
| 5. Los desarrolladores reciben copias completas. | Mínimo privilegio. | Acceso excesivo a información personal. | Entregar únicamente los datos necesarios. |
| 6. Las copias de desarrollo contienen datos reales. | Privacidad por diseño. | Filtración de información durante las pruebas. | Utilizar datos ficticios o anonimizados. |
| 7. Marketing utiliza correos para promociones sin una finalidad claramente documentada. | Limitación de la finalidad. | Uso de datos sin cumplir los requisitos aplicables. | Documentar la finalidad y verificar el fundamento jurídico. |
| 8. No se documenta la finalidad de cada dato. | Transparencia y responsabilidad. | Uso indebido de información personal. | Crear un inventario de datos y sus finalidades. |
| 9. Todos los empleados de analítica tienen acceso a los mismos datos. | Control de acceso. | Consultas no autorizadas o innecesarias. | Asignar permisos según las funciones de cada empleado. |
| 10. No se especifican controles de auditoría. | Trazabilidad. | Dificultad para detectar accesos indebidos. | Registrar y revisar los accesos a información sensible. |
| 11. No hay un procedimiento definido para eliminar datos innecesarios. | Limitación de la conservación. | Permanencia injustificada de información. | Implementar procedimientos de eliminación segura. |
| 12. No se describen medidas para proteger las copias de la base de datos. | Confidencialidad. | Robo o divulgación de información. | Restringir el acceso y cifrar las copias de seguridad y desarrollo. |
